# I SEE YOU 安卓测试版：原界面＋交接包核心

分支：`codex/handoff-core-original-ui`。应用名称为 **I SEE YOU 测试版**，安装标识与交接包和其他版本不同，不会覆盖原应用的数据。面向 Android 8 及以上的 ARM64 手机；不是 iPhone 安装包，也不是打开远程网站的空壳。

## 实际接入

首页仍由仓库原有的像素 HTML、CSS、图标组成。页面随 APK 一起安装，按钮经过限于应用本地页面的消息通道调用 `AssistantController`。网页不申请摄像头、不执行浏览器版 YOLO、不连接网页原有的千问接口。采用 Android 官方的 [WebView 本地页面加载方式](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)。

安卓核心来自用户提供的 `yolo+千问快速识别` 交接包，已接入：

- CameraX 手机相机、ESP32 视频源、单路帧路由。
- TFLite 本机 YOLO、中文类别映射、稳定两帧候选。
- 三次物品外观样本采集，裁剪图和颜色统计特征存入应用私有目录及 Room 数据库。
- 使用个人外观样本排序候选，千问独立 HTTP 接口一次接收整图与裁剪图复核。
- 图片复核与本地识别分开运行，等待复核时仍处理新画面。
- AOQ 原生实时语音、麦克风、语音指令及系统语音提示。
- 任务状态、继续寻找、拿到、取消、超时后继续本地搜索。
- ESP32 BLE 扫描、配网、设备口令、HTTP 控制与 MJPEG 视频。入口位于原有 Aa 设置 → 更多选项 → 摄像头与硬件。

原有记录入口继续可用：物品列表、编辑、删除均读写同一个 Room 物品库，不是另一套网页物品库。对话列表保留原页面存储实现，位于应用私有 WebView 数据中。场景选择用于对话记录标识；交接包的物品库本身不区分“家”和“普通场景”，两种场景均可学习物品外观。

原生核心始终处理当前帧。页面只给本轮正在寻找、实际存在个人记忆的目标画候选框；确认框须来自核心确认状态并与当前框重合，超时撤销。进入后台、结束或关闭摄像头会停止相机、麦克风和任务，清理本轮临时候选图片；长期物品样本保留。编辑或删除正在寻找的记忆会取消该任务。

## 如何测试

1. 安装最新构建生成的 `app-debug.apk`，打开“I SEE YOU 测试版”。
2. 点“开始”，允许相机和麦克风；本机 YOLO 不需要下载网页模型。
3. 对准物品，说“记住绿色水杯”。按提示把物品放在中央、缓慢转动，看到实际采集到 3 个样本的保存回执。
4. 说“帮我找绿色水杯”或从记录里点“找这件”。本地提出候选，千问确认后才给出找到提示；说“拿到了”完成。
5. 重启应用，在记录里检查物品仍存在，再寻找同一物品。
6. 有硬件后，从设置扫描设备、填写同一 2.4 GHz Wi-Fi 并配网，切换画面来源后开始。也可手工填写局域网地址；Arduino 兼容流地址通常为 `http://设备IP:81/stream`。

读屏选项会关闭应用额外的语音输出，由 TalkBack 读取页面提示；“朗读本地文字回答”控制系统提示声音。找物提示沿用交接包的手机语音，普通对话使用千问声音。

## 云端边界

YOLO 和个人物品样本在手机。千问语音与图片复核需要联网。

独立测试网关：`https://i-see-you-android-core-test.pages.dev`，代码位于 `cloudflare/android/`。使用交接包指定的服务地址与模型，长期测试密钥仅保存在此测试网关；不会编译进 APK、网页、GitHub 仓库或构建日志。App 只取得临时语音凭证，候选图片由网关转交。网关设有请求频率与图片大小限制。正式网站和上一版网页实验的配置均不变。

## 构建与检查

```sh
npm ci
npm run build:android
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

本机需要 JDK 17、Android SDK 36。仓库也提供 `.github/workflows/android-test.yml`，推送本测试分支即可生成安装包及检查报告。构建从仓库现有模型分片还原原始 `exp.tflite` 并校验 SHA-256，不重复提交模型，也不读取交接包的环境变量文件来构建 APK。

页面交互检查：`node tests/android-ui-browser.cjs`。这是页面与原生消息协议的检查，不能代替 Android 真机相机、麦克风、蓝牙和硬件验收。网关检查：`node --test tests/android-gateway.test.mjs`。

## 明确的限制

- 交接说明中的 141 类与实际模型不符；模型和标签实际为 **80 类**，已修正打包检查。无对应类别的物品依照原核心交由千问低频检查。
- 外观记忆是交接包的颜色统计特征，不是可以可靠区分所有同色同类物品的身份识别模型；采集三次不代表已自动验证三个不同角度。
- 千问可能超时，手机 TTS 也取决于设备是否有中文语音资源。本地候选不能单独宣布找到。
- 构建、核心单元检查、页面操作和后台接口可以自动验证；未连接真实安卓手机和 ESP32 时，不宣称已经完成相机、语音及 BLE 真机验收。

原交接包来源、导入与适配范围记录于本目录，Android 厂商 SDK 与模型仍保留原始文件；未将交接包的私有配置、原 APK 或个人数据提交到 GitHub。
