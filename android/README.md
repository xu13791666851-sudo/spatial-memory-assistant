# I SEE YOU 安卓原生界面测试版 0.5.0

该版本按确认后的界面稿调整安卓首页：像素风 I SEE YOU 字标、大画面、语音找物与对话记录。三点菜单只有“连接摄像头”和“切换画面来源”；Wi-Fi 表单在连接时按需出现，地址、固件和调试信息不展示给普通用户。

## 相机和 YOLO

首页直接使用交接包的 CameraX PreviewView 和 YoloPreviewView。本地相机的连续预览不再经过 JPEG 重新编码、Base64 和 WebView 图片更新，避免新增的预览中转开销。相机的分析转换限制为每秒最多 5 帧，预览帧率不受这个限制；语音连接失败会关闭录音资源，避免持续占用识别资源。

所有实际 YOLO 检测结果均会画框，包括未开始寻找、采集记忆和寻找时。框上的类别、分数来自模型；类别检测不等于已经确认某个个人物品。找到提示仍由原来的候选筛选、外观比对、千问复核流程决定。

模型、80 类标签、中文类别映射、三次外观采集、Room 物品库、找物状态机、千问实时语音与图片复核沿用交接包导入后的核心。没有用示例录像或图片代替安装包的摄像头。

## 用户操作

1. 打开“I SEE YOU 原生测试”，点击“语音找物”，允许相机和麦克风。
2. 等待“语音已就绪”，说“记住绿色水杯”，按提示完成三个外观样本；以实际保存回执为准。
3. 再说“帮我找绿色水杯”。本地检测框持续显示；疑似目标由千问复核，通过后播报方向。可以说“拿到了”“取消寻找”等原版指令。
4. 对话记录中查看左右对话、物品记忆，支持“找这件”、编辑、删除，也保留文字输入作为备用。
5. 连接 ESP32：三点 → 连接摄像头 → 搜索附近摄像头 → 选择设备 → 输入 2.4 GHz Wi-Fi 名称与密码。只有设备实际返回配网成功才提示连上 Wi-Fi。
6. 三点 → 切换画面来源 → 外接摄像头。已在识别时会停止旧来源，再启动新来源；未开始时先选择来源，再点语音找物。
7. 点击“结束”或离开应用会停止相机、语音及任务。关闭配对页会取消蓝牙操作，Wi-Fi 密码不写入偏好设置。

旧版本保持安装：本版标识为 `com.spatialmemory.assistant.iseeyou.native.debug`，与此前测试包分开，不要求卸载旧包或删除旧记忆。新包的私有物品库独立，需要在新包重新记住物品。以后本机使用同一签名构建可覆盖升级本版。不能把不同安装标识的物品库说成已经自动迁移。

## 工程入口与完整性

原版 HardwareDebugActivity 保留原始工程按钮和模拟 ESP32 源，仅在 debug 包内部注册，不导出、不放进普通用户菜单。它也使用同一个测试网关，不把长期密钥编译进 APK。正常入口无需工程页便可完成手机相机、语音、记忆、找物、BLE 配网和 ESP32 视频源切换。

原生记录页读取核心正在使用的同一个 Room 物品库。对话按左右气泡展示并保存在本版应用私有存储，最多保留最近 200 条。主页无额外网页模型、浏览器相机或网页语音层。

## 构建和验证

```sh
node scripts/build-android-assets.mjs
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest
```

需要 JDK 17、Android SDK 36。默认 ARM64、Android 8 以上。构建脚本还原并校验交接包原始 `exp.tflite`；旧的 WebView 页面不打入本版 APK。GitHub Actions 继续提供构建及检查报告。

自动检查包含：核心单元检查、模型和标签打包、真实模型识别公共公交车照片、无记忆条件下绘制全部检测框、三个样本在实际 Room 库中保存及重新读取、模拟器 CameraX 帧进入 YOLO 与停止。

千问使用 `https://i-see-you-android-core-test.pages.dev` 测试网关。长期密钥只在后台，安装包获取临时语音凭证；图片复核也由网关转交。语音连接保留服务端提供的 TCP 备用端口，不丢弃回退线路。本地 YOLO 不依赖网络，千问语音与复核需要联网。

## 验证范围

模拟器运行不能代替实体安卓手机的性能、麦克风、厂商权限和真实 ESP32 BLE / Wi-Fi 验收。只有拿到实际检测结果才显示识别框；不把演示设备标为已连接，不保证 YOLO 能识别所有物品，也不把类别分数当作物品身份确认。
