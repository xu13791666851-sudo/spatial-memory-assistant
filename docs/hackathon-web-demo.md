# I SEE YOU：手机摄像头完整流程演示

本分支 `codex/hackathon-web-demo` 把安卓交接包的手机摄像头流程移植为可独立部署的网页应用，保留主分支最新像素界面。它不运行 APK，不冒充安卓真机；硬件连接独立演示，当前网页使用手机摄像头。

## 演示什么

1. 用 Safari 或 Chrome 在 HTTPS 独立窗口打开应用，点击“开始”，允许相机和麦克风。
2. 说“帮我看看眼前有什么”，等待基于新画面的回答。
3. 把物品放在中央，说“帮我记住蓝色水杯”。缓慢转动，等待采集三个实际外观样本并核对名称、颜色和外形。
4. 只有样本核对成功且存储提交成功才会说“已经记住”。模糊、名称不符、网络失败均不会宣称保存成功，也不会覆盖旧记录。
5. 打开“对话记录 → 物品记忆”，查看实际保存的外观和位置。位置不清楚时会明确显示“已记住外观，尚未记录位置”。
6. 结束后刷新或重新打开同一网址，再说“帮我找蓝色水杯”。系统会读取已保存的三个外观样本，与当前画面中的候选比对，再让千问核对。
7. 候选框只用于正在寻找且有记忆的物品。最终核对通过才显示绿色框；没有 YOLO 框不等于物品不存在，会低频检查完整画面。多个相近记忆会询问要找哪件。
8. 可说“拿到了”“停止找物”“暂停对话”“继续对话”“结束对话”；也可从记录页文字输入。历史位置会说明来源，不当作现在确认的位置。
9. 可编辑或删除记忆、重听回答、查看左右对话、回到首页。打开记录不会中断画面或重建当前目标。
10. 点击“结束”、切到后台或离开页面，关闭摄像头、麦克风和当前任务。每次连续使用上限为10分钟；后台还会清理失联会话。

## 与安卓的关系

| 项目 | 安卓测试包 | 这个网页演示 |
|---|---|---|
| 页面 | 原有像素页面 | 同一页面及交互组件 |
| 相机、麦克风 | 安卓系统 | 浏览器授权 |
| YOLO | 手机本机 TFLite | 后台 LiteRT，使用完全相同的原始模型 |
| 外观特征 | 64×64 RGB、48维颜色统计 | 移植同样的缩放、分箱和归一化规则 |
| 候选排序 | 35% 检测分数＋65% 外观相似度 | 同样的排序规则与双帧稳定检查 |
| 三次样本 | 手机私有文件及 Room | 后台 SQLite 事务及图片数据 |
| 千问确认 | 完整画面与候选图 | 完整画面、候选图及实际保存的样本图 |
| 语音 | AOQ 安卓 SDK | 后台鉴权的 WebSocket、浏览器音频 |
| 离线、ESP32 配网 | 安卓保留 | 本演示不包含，硬件另演示 |

网页额外核对采集样本是否符合用户说的物品，避免把蓝杯误记成绿杯；只有成功写入数据库才发保存回执。这是有针对性的改进，不宣称两端内部实现、速度或准确率完全一样。

模型实际为80类，文件 SHA-256：`9db0427fb26b590b6293b28da6071f3f62bdaa188a2c08cfe9e09af5032ee6b4`。颜色统计不是可靠的物品身份模型，同色同形物品、低光和遮挡仍可能影响结果。未知类别交由千问检查，不凭本地漏检宣布不存在。不估算行走路线或厘米距离。

## 记录保存在哪里

每个浏览器通过自己的签名 Cookie 隔离物品记忆。刷新和后台重启后仍可读取；不与安卓安装包、其他网址、其他浏览器或其他手机自动同步。清除网站 Cookie 或使用新的隐私窗口，会获得新的独立身份。对话文字沿用原界面，保存在当前浏览器中，可在记录页删除。

后台数据目录由 `DEMO_DATA_DIR` 指定，包含私有数据库、样本图及会话签名密钥，不公开提供下载。ModelScope 推荐 `/mnt/workspace/iseeyou`，移动或重建空间前应备份数据。网页与压缩包均不包含千问长期密钥。

## 本地运行

需要 Node.js 22 和 Python 3.11。

```sh
npm ci
npm run build:demo
python -m pip install -r demo/requirements.txt
# 通过环境变量设置 QWEN_API_KEY，不写进源码或浏览器
python -m uvicorn demo.server:app --host 0.0.0.0 --port 7860
```

本机打开 `http://127.0.0.1:7860/`。手机摄像头及麦克风需要 HTTPS，不能把电脑的 127.0.0.1 地址直接发给手机。推荐使用正式部署的 HTTPS 地址；临时隧道仅供调试，依赖电脑及网络持续运行，不能冒充已独立部署的比赛链接。

## 魔搭创空间部署

提供根目录 Dockerfile，服务监听 `0.0.0.0:7860`。选择平台当前可用的免费 CPU Docker 资源，按平台要求完成账号与 Docker 空间开通。在空间的秘密变量中设置 `QWEN_API_KEY`，普通变量设置 `DEMO_DATA_DIR=/mnt/workspace/iseeyou`。上传完整提交包或同步代码后构建，检查 `/health` 的模型就绪状态，再用应用的 HTTPS 独立窗口测试。

```sh
docker build -t i-see-you-web-demo .
docker run --rm -p 7860:7860 --env QWEN_API_KEY -v iseeyou-data:/mnt/workspace/iseeyou i-see-you-web-demo
```

不在网页填写或暴露长期密钥。不把安卓 APK 当作创空间应用入口。iPhone 尽量使用 Safari 独立窗口，避免内嵌网页限制权限或第三方 Cookie。

## 检查与实际边界

```sh
python -m unittest discover -s tests -p demo_test.py -v
```

自动检查覆盖：三个样本实际存储、服务器重启后读取、用户隔离、过期和取消结果丢弃、采集中断不覆盖旧记忆、编辑删除及冲突检查、外观排序、模糊名称选择、签名身份和跨站请求拦截。

`tests/demo-browser.cjs` 使用真实后台、原模型和真实千问。仅摄像头与麦克风输入由测试文件控制；已实际验证语音转文字触发采集、三个样本保存、刷新后找回、千问确认与识别框、修改删除、用户隔离、停止媒体和手机尺寸布局。测试媒体由本地脚本生成，运行时通过 `PLAYWRIGHT_MODULE` 指向可用的 Playwright，`DEMO_TEST_URL` 指向被测服务。

这不是 iPhone 真机验收报告。部署后仍需检查真实 Safari 的相机、麦克风、扬声器和网络。未完成正式托管时，不能把临时调试链接描述为长期可用的比赛部署。
