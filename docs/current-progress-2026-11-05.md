# 当前开发进度（2026-11-05）

这是安卓平板与电脑处理中心的开发快照。历史位置读取已在平板验证；完整的“看到当前物品、与记忆照片核对、准确确认当前位置”尚未通过现场验收。

## 已实现并验证

- 安卓连接电脑，摄像头向电脑发送新画面，使用本地YOLO产生候选。
- 电脑统一保存场景、外观及位置来源，读取已有物品与位置历史。
- 平板按物品展示记忆、位置历史和查找入口；新会话清除临时指代，保留物品记录。
- 常见别称、颜色名称和连续追问处理；同类多物品不自动合并。
- 瓶状水杯可进入cup和bottle候选，粗略外观特征用于排序，最终身份判断交给Jev。
- 未核实裁图可补充当时原始场景；本地没有候选框时，可用整幅当前画面继续核对。
- 错误分项记录、过期结果提示，避免把旧位置说成当前确认。
- Supabase私有备份与恢复路径，以及下载校验；本轮为隔离流程验证。

## 现场尚未通过

- 稳定获得可辨认整件物品的参考照片。现场发现旧裁图过小，原场景方向也需核对。
- Jev稳定完成比较。实际收到过不确定结果，也出现超时和网络失败。
- 慢响应下连续确认当前目标。返回时画面过期或候选变化，仍可能无法确认当前位置。
- 新记忆到关闭重开、找回同一物品的完整验收，以及连续语音全过程验收。
- 本轮真实云端备份恢复后的完整找物验收。

## 验证记录

- 电脑端66项流程检查通过，含新增杯子/瓶子候选、参考场景补充和追问检查。
- 安卓75项本地检查通过，主程序与额外测试包构建成功。额外测试包在设备上安装被系统拒绝，不声称设备自动测试通过。
- 公共图本地YOLO检测、公开生成杯子图片的真实看图请求成功。
- 平板真实读取已有位置历史成功；现场真实YOLO和Jev调用已执行，完整找物结论为未通过。
- 原有用户记忆经内容校验保留；个人照片、数据库、令牌、配对地址、证书和现场截图均不上传。
