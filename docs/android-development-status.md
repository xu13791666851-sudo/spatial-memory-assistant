## 可重复构建

在仓库根目录用 PowerShell 执行：

```powershell
.\scripts\build-android.ps1 -IsolatedTabletTest
```

已有完整依赖缓存时可增加 `-Offline`。需要编译自动检查用的辅助包时增加 `-IncludeDeviceTestPackage`。默认构建会准备并校验原始模型，执行核心检查和静态检查，生成安装包并验证签名，最后输出检查摘要。

脚本优先使用 `JAVA_HOME`、`ANDROID_HOME`，也可传入 `-JavaHomePath`、`-SdkPath`，或使用本机 `.codex/android-tools` 中的 JDK 17、SDK 36 与同版本 Gradle 缓存。工具路径只在脚本进程中生效。

## 安装与更新

```powershell
.\scripts\install-android-tablet-test.ps1 -DeviceSerial 设备编号 -ApkPath 安装包完整路径
```

默认只做新安装；发现同名测试应用时拒绝替换。脚本不卸载、不清数据、不降级，也不自动授予相机或麦克风权限。用户在应用弹窗中决定权限。

更新本项目刚安装的测试版时，必须额外传 `-UpdateOwnedTestApp -ExpectedInstalledSha256 已知旧安装包摘要`。脚本先读取并核对这一测试应用的安装包，完全匹配已知旧版后才允许保留数据的覆盖升级，签名由安卓再次验证。若不是已知版本，直接拒绝。不能用此开关更新其他应用。

Windows 部分 SDK 工具不能正确读取中文完整路径，安装脚本会在电脑临时目录准备经过摘要核对的副本；只清理自己创建的电脑临时文件，不清理平板文件。
