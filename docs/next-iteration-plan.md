# 后续任务顺序

2026-11-03：0.11.0 已实现先保存当时画面、外观与位置分别确认、查询实际记录，以及受控的统一回复。原 0.10.0 现场失败记录保留，不能以旧检查替代本轮验收。

1. **核对现场完整流程。** 对真实物品说“记住这个杯子”，再问“记住了吗”“上次在哪”，结束重开再查。数据库、界面和声音一致才算通过；要覆盖不同杯子与桌面，不能只用同一张回放图片。
2. **根据分项原因提高识别。** 区分目标不明确、目标范围未确定、位置未确认和网络失败。场景始终保留，不靠统一降低判断门槛获得假成功。
3. **扩展多轮理解。** 现有明确指令、常见指代与千问结构化意图先覆盖核心操作，再用真实对话补充更复杂的省略、澄清与任务切换；不宣称已能理解所有自然说法。
4. **补齐找物漏检和位置细节。** YOLO 漏掉已记物品时增加受控的独立视觉补扫，继续严格确认个体身份；更细的房间与参照需要实际证据。
5. **ESP32 联调。** 固件由队友负责，继续保留 XIAO ESP32S3 的统一画面入口，不把安卓核心或云端密钥烧入摄像头。

继续使用安卓原生应用和 Supabase 私有备份，不新增用户需要配置的设置页。见 [当前流程](android-controlled-memory.md) 与 [原问题及设计依据](memory-flow-reset.md)。
