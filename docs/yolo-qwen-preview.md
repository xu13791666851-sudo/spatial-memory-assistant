测试分支：`codex/yolo-qwen-preview`。基于主分支 `f418a1846547e900890ac9acfa89b128e8789aa2`（2026-10-20，队友的 PR #8 已合并）。保留其中的连续找物、外观比对、无名称物品记忆、自然语言位置更新和故障恢复。

测试入口：https://i-see-you-yolo-preview.pages.dev/video/

## 接入范围

保持现有 HTML、CSS、按钮、场景选择、语音、记录和物品记忆界面不变。移植交接包的模型预处理、识别结果解析、同类别框去重、中文目标映射和稳定候选规则，不把 Android 页面或调试界面搬进网页，也不复制包内的密钥。

交接说明写“141 类”，但实测标签数为 **80**，模型输出为 `[1,84,8400]`，输入为 `[1,3,640,640]` 的浮点 RGB 数据。钥匙、耳机等无对应类别的物品继续由千问识别，不能把 YOLO 没检测到当成物品不存在。

## 实际流程

1. 开启摄像头后在后台预加载原始 TFLite 模型；首页不会等待模型下载才显示。
2. 连续找物时，支持的类别先在独立 Worker 中识别两张新画面。候选分数至少 0.5，同类框重叠比例至少 0.2，且每张画面中该类别只有一件候选，才算稳定。
3. 将最后一张本地检查过的完整画面交给原有千问流程。仍检查画面回执、图像输入、目标是否可见，以及已保存的外观是否相符。位置参照仍由完整画面提供。
4. 稳定本地候选与千问确认同时通过后，可结束寻找，省去再等待下一轮云端确认。YOLO 不能单独宣布找到，也不能单独保存或更新记忆。
5. 模型未准备好、不支持某类别、出现多个同类物品、低分、加载失败或设备较慢时，沿用原来的千问路径与两次云端确认。本地双帧最多等待 2.5 秒，超时后本轮会话停用加速，不反复增加等待。

普通问答、描述环境、询问历史位置、直接看图记住和无名称物品识别沿用队友版本；YOLO 仅参与连续找物。暂停、取消、切换场景、关闭相机、结束会话时，旧识别结果不能继续提交、保存或提示找到。

## 运行与发布

```sh
npm ci
npm run build:cloudflare
node --test tests/*.test.mjs
npm run test:yolo:browser
npm run deploy:yolo-preview
```

浏览器检查沿用仓库的 Playwright 依赖方式，可用 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright。

此分支的 `wrangler.jsonc` **专门指向测试 Worker** `i-see-you-yolo-preview`，避免常规部署命令发布正式站。Pages 配置在 `cloudflare/yolo-pages/wrangler.jsonc`。测试站通过私有服务连接调用现有后台，运行时密钥不用重新复制，正式站的配置、部署及网址不变。测试请求会使用同一个千问账号和原有请求频率额度。

首次创建同名 Pages 项目，生产分支填 `main`，生产及预览环境的 `MEMORY_API` 绑定到测试 Worker。发布命令只部署测试 Worker 和此测试 Pages 项目，不合并主分支。

模型原始大小为 38,073,903 字节，以 5 个文件分片保存，加载时逐片核对 SHA-256 并在内存中还原。每片小于 Cloudflare 的单文件限制；有版本标识的模型分片和依赖可缓存，普通网页和识别接口不缓存。

测试站为本地识别启用跨来源隔离，浏览器支持时使用最多 4 个计算线程。TensorFlow 运行库需要的动态代码许可仅放在无 DOM 的检测 Worker 响应上；页面本身不允许 `unsafe-eval`。所有运行库和模型从本站加载。

## 已验证与限制

真实浏览器已加载并执行交接包模型，在现有桌面测试图中检出水杯、电脑、书和盆栽。电脑本地 4 线程运行约 0.6～0.75 秒/帧；上线后复测约 0.8～1.2 秒/帧，稳定双帧约 2.02 秒。千问对最后一张本地检查过的图片返回了清晰画面回执、目标可见及水杯的相对位置，样例请求耗时约 4.6 秒。这些是开发电脑的样例测试，不代表手机性能或整体识别准确率。单线程样例约 1.7 秒/帧，会走速度较慢的回退分支。

167 项自动检查通过，原有 9 组页面浏览器检查通过。生成的三个 HTML 与四个 CSS 文件和主分支逐字节一致。线上真实语音连接成功，收到“你好”的回答与音频轨道；测试页在 390px 宽度下无横向溢出。首次无缓存模型加载样例约 54 秒，等待期间继续使用原千问流程。真实手机速度尚未验收。

首次下载模型需要流量和时间。手机浏览器、网络、散热和内存条件不同，不能保证一定快于纯千问。错误类别、低光、遮挡、多件相似物品等仍可能识别失败，最终提示受千问确认与现有证据校验约束。未将此实验合并到主分支。
