## SVG 文件

- `designs/retro-pixel-ui.svg`：左右对照完整界面稿。
- `designs/retro-pixel-home.svg`：390×844 首页。
- `designs/retro-pixel-records.svg`：390×844 对话记录。

SVG 是从生成后的真实页面几何位置导出的文字、路径和形状，不包含脚本或 foreignObject，也没有嵌入整张界面截图。摄像头区域嵌入示例 JPEG，其他界面均为矢量。示例照片不作为实际摄像头背景使用。

## 一致性范围

图稿与网页使用相同配色、SVG 图形和控件布局，固定390×844、标准文字大小及相同示例状态下可对照。不同浏览器字体绘制可能有细微差异。用户的真实画面、正在连接/暂停等状态、文字长度、大字设置和屏幕尺寸会改变内容，不能用静态示例覆盖这些真实状态。

网页保留真实按钮、输入框、对话记录和媒体节点，而不是把整张 SVG 盖在页面上。这样视觉一致时，原有的找物、存储、读屏焦点和摄像头功能仍可工作。

## 重新导出

先运行 `node scripts/build-netlify.mjs`，再运行 `node scripts/export-retro-svg.cjs`，最后再次构建以发布 SVG 文件。导出使用隔离浏览器与模拟接口，不连接真实模型，也不会写入使用者的浏览器记录。

浏览器检查覆盖启动、真实生成页面中的会话流程、左右气泡、任务保留、记忆修改/刷新、320/390/1024宽度和放大文字。未以此声称真实模型识别准确率或手机读屏验收已完成。
