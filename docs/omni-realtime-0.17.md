# 0.17 Omni Realtime 候选版（2026-11-05）

## 改动

- 全部新增电脑视觉与补充意图请求固定为 `qwen3.8-omni-flash-realtime`。安卓原本已经使用同一型号进行实时语音，继续兼容现有 0.16 APK。
- Realtime WebSocket 长连接复用，手动提交每次固定画面并接收完整结构化文本；未完整结束的输出不作为成功。显式配置 Tina，避免服务默认音色不兼容。只接收文本结果，由现有应用统一播报实际结果。
- 不调用非实时 Omni、VL 或 Jev。旧安卓即便发送 OpenRouter key，电脑也忽略它。
- 记忆先保存场景，再执行一次 Omni 分析并保存外观及观察位置，不等待第二模型。标记为 CAMERA_OBSERVED，不冒充独立核实的位置；历史查询继续读数据库。既有 v2 数据与备份格式保持兼容。
- 当前候选与历史参考拼成带 CURRENT / HISTORICAL REFERENCE 标签的一张图片，绑定请求 frameId。参考始终不是当前存在证据。模糊、缺少独特细节或同款歧义返回不确定，不把模型生成的数字当作身份概率。
- 意图连接与图像连接分开，避免纯文字意图请求继承旧画面；非聊天意图的自由回答被丢弃，后续操作读取实际数据。
- 检测后加入保守的相邻帧跟踪：唯一重叠对应才沿用编号，遮挡、丢失、同类重叠、超过 1.5 秒间隔或换相机均中断；不新增推理模型或显卡要求。这不是跨场景个体重识别。
- 超过旧 3 秒时效的比较，只有同一候选至少连续跟踪 3 帧、最新检测足够新且总等待不超过 8 秒时才可使用，方向来自最新框。否则继续寻找，不能播报旧位置。
- 取消/新会话关闭旧连接，迟到结果不能回复新任务；连接断开后下一次请求重建。连续 3 次比较失败后暂停 15 秒，不无限重试。

## 本地验证

- Node.js 24，原有 66 项电脑检查及新增 Realtime、记忆、身份不确定、延时/丢跟踪和意图隔离检查通过。
- Python 相邻帧跟踪 3 项检查通过：连续移动、丢失/切源/间隔重置、重叠歧义。
- 真实官方 Realtime 握手返回准确型号。公共杯子图片场景问答首次约 0.7 秒，仅作为接入烟测。
- 最终公共固定图请求：记忆描述 1270ms；同图比较 814ms，因杯子无独特标记返回 UNCERTAIN；公交车与杯子比较 891ms，返回 UNCERTAIN、没有确认杯子存在；独立意图请求 848ms，正确分流 describe。
- 上述是少量公共图实测，不是 P95 或真实物品准确率。没有拍摄现场、读取私人记忆或上传云备份。
- 当前 Mac 没有连接华为电脑/小米平板，也没有原 YOLO 权重及完整安卓 SDK。本轮没有重新执行硬件采集、本地真实 YOLO 推理、安卓安装或连续真实语音验收。

## 华为电脑更新与实物测试

1. 停止旧电脑服务，备份旧源代码和 runtime。将更新包里的 pc-gateway 源文件覆盖到原目录；保留原 runtime、models/yolo11s.pt、.venv 及配对信息，不删除数据。
2. 在该华为电脑设置百炼 API key。可以使用环境变量，或复制 pc-gateway/.env.example 为 .env 后仅在本机填写。此 Mac 可调用，不代表华为电脑已经配置。
3. 运行“启动电脑服务.ps1”。确认 /health 为 0.17.0、visionModel 为 qwen3.8-omni-flash-realtime、yoloReady 为 true。平板继续沿用原连接。
4. 先运行公开图片自检。实物测试由用户从当前场景任意指定物品，不限定杯子或预设清单。对每件目标依次说“记住这个〈物品名〉”“记住了吗”“上次在哪”，关闭重开后重查。
5. 移动物品后说“现在帮我找”。分别覆盖缓慢移动、遮挡后重现、画面里没有目标、多个同类或同色物品；确认旧位置不被说成当前位置、无特征同款不被强行确认。
6. 对话中途取消、新会话、断网恢复，检查不串旧回答、不丢已存记忆。统计完整确认耗时、超时率、误认率，再决定是否补充 VL。

## 任意场景物品测试范围

杯子仅是早期公共图片样本，不是产品可选物品白名单。现场可指定任何可见物品；以下例子用于覆盖难度，不限制用户选择。

| 情况 | 示例 | 核对内容 |
| --- | --- | --- |
| 常见检测类别 | 手机、鼠标、书本、遥控器、杯子 | 记忆、重开查询、移动后寻找与最新方位 |
| 无预设检测类别 | 钱包、钥匙、耳机、充电线、药盒、任意小摆件 | 无 YOLO 框仍提交当前整幅画面给 Omni；不得因类别不支持直接判断不存在 |
| 多件相似物品 | 两支笔、两本书、两个同色盒子 | 有歧义时询问是哪件，不自动合并记录；没有独特细节时不强认个体 |
| 指代不明确 | “记住这个”，但画面中有多件物品 | 请求说明目标或调整镜头，不任意选择 |
| 困难观察 | 小物件、透明瓶、反光金属、遮挡、暗光、运动模糊 | 保留场景、说明未看清，不虚报保存完成或当前位置 |
| 目标离开场景 | 拿走目标后再问“现在在哪” | 区分历史位置与当前观察，不能用参考照片证明当前存在 |

所有目标均检查保存、查询、重开、移动寻找、拿取确认、取消与断线恢复。按类别分别记录完整响应耗时和误认/漏认，不用杯子的一次成功代表其他物品。

本地新增钱包、耳机、药盒、钥匙、充电线、遥控器共 6 项模拟流程检查，覆盖记忆、历史查询、无候选框整图核对与不确定结果。模拟图片内容不代表这些类别已通过真实识别测试。

“任意物品可作为目标”不等于“任意物品都能可靠识别”。当前没有本地检测框的目标可以整图核对，但不能使用依赖本地框的连续跟踪来延长旧画面有效期；其位置确认仍受原有新鲜度约束。跨类别识别和同类个体区分均以实物测试为准。
